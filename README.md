# GDG Cloud Hanoi Photobooth

A photobooth application built with Flutter and Firebase for **GDG Cloud Hanoi**, inspired by the [Google I/O Photobooth](https://photobooth.flutter.dev) project.

## Getting Started

Run the project on web:

```sh
flutter run -d chrome
```

Build for web:

```sh
flutter build web
```
